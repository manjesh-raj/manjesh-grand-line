# 2026-11-26 - What the floating bar's pages left behind

P-03's second part removed each page's hidden floating-bar presentation, page by page.
The sweep that followed removed the kit API those presentations were the last callers of.
Nothing a page draws changed.

- `HelmModuleCard` 1.5.0 → 2.0.0 (major): removed the `.usageReport`, `.usageReportDense`, `.ringWithLines` and `.kpis` bodies. No page drew them after Home's dashboard and the floating bar's hub went. The usage report itself stays, as the detail `.heroSplit` draws beside its panel.
- `HelmResponsiveGrid` 1.1.0 → 2.0.0 (major): removed the fixed proportional layout (`dashboardColumns`, `proportionalUnit`, `proportionalWidth`, `fitsProportionally` and `proportionalRow`). Home's hand-placed dashboard was its only caller, and it went in P-03.
- `HelmSplitPage` 1.2.0 → 2.0.0 (major): removed `pageForcesCollapse` and the `.pageGroundWithEdge` sidebar surface. Tasks' page column was the only page that used either, and it went in P-03. The width rule (`collapsesBelowWidth`) is now the one thing besides the captain that puts a column away.
