# Helm kit releases

One file per release, named `YYYY-MM-DD-<slug>.md`.
The rules and the bullet format are in [`../helm-kit-versions.md`](../helm-kit-versions.md).

A release file looks like this:

```
# 2026-11-26 - The short title of the change

One or two sentences on why, naming the proposal or the pull request.

- `HelmSearchField` 1.2.0 → 1.3.0 (minor): what changed.
```

The kit's number is the date of the newest file here.
